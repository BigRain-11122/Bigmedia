## §0 一句话总纲

**诚实给底线，工艺给上限**——重写不是删事实，是给事实排序。

## §1 八条铁律（每条=可验证假设·校准指标在 research 件 §2）

| # | 铁律 | 稿件自检问句 |
|---|---|---|
| L1 | 3 秒张力钩子 | 前 3 秒有没有冲突/悬念/反常识？删掉开场自我介绍了吗？ |
| L2 | 一视频一论点 | 60s 只讲一件事了吗？每拍 20-40 字、一拍一信息了吗？ |
| L3 | 具体压倒形容 | 数字/时间戳/名词到位了吗？形容词堆叠清了吗？ |
| L4 | 递进结构 | 每 10s 有新信息点吗？情绪有峰谷吗？结尾回环了吗？ |
| L5 | 说人话 | 机制词每个都配人话翻译了吗？文档腔清了吗？ |
| L6 | 社交货币 CTA | 「转给XX」给了理由（利益/身份/情绪）吗？裸 CTA 删了吗？ |
| L7 | 字卡第二轨 | 字卡是锚点词/数字，不是口播复读机吗？ |
| L8 | 真实感优先 | 实录/真数据/糙细节，替代包装感了吗？ |

## §2 平台适配速查（证据=user-research v1.1/v1.3 官方采）

- **视频号**：熟人语态+转发动机（算法=好友关系推荐加权）——CTA 必须具体到人。
- **B站**：标题三件套+系列化纵深；AI 赛道拥挤→差异化=真实台账独家。
- **YouTube**：标题=搜索词+利益点；窄垂直入推荐池。
- **小红书**：痛点搜索词+清单体（playbook 既定）。

## §2.5 趣律（v1.1 · O-19260923-1924「一点都没意思」触发 · 证据=research/bilibili-craft-research-v1.md §2）

八条铁律管「讲得对」，趣律管「有意思」——**缺趣=不合格**（CEO 三审裁定）：

| # | 趣律 | 自检问句 |
|---|---|---|
| L9 | 作死挑战骨架 | 过程是赌局吗？（「我干了件作死的事」>「本系统实现了」） |
| L10 | 翻车=素材 | 自嘲与真实事故出境了吗？成功汇报删了吗？ |
| L11 | 弹幕梗位 | 每 60s 至少一个可玩梗位吗？（甩锅/催更/打脸/离谱） |
| L12 | 当事人视角 | 全程「我」在经历，还是「它」在汇报？ |
| L13 | 自指梗 | 「这条视频就是 AI 剪的」类自指出场了吗？ |
| L14 | 评论区钩 | 留了让弹幕接话的钩子吗？ |

真实律红线不变：一切「事故」须为实况（432 全灭/返工三轮/R5 超时=今日真实台账）；趣律禁止编造翻车。

## §2.6 品牌声线正典（v1.2 · CEO 令 O-20260923-2136-bm-a「声音更加赛博一点，机器人一点，文案也是」）

- **叙述者**：视频口播叙述者=**机器**（三号公司 BigStream AI 本机自报家门），Jason 转为被报告的主角（「我的老板，全公司唯一的人类」）；Jason 本人原声出镜态另存（人设卡 §二 叙述者双态制）。
- **语体**=系统日志体——系统启动/扫描/检测到/自动唤醒/指令 等机器动词做骨架；**词汇白名单律**：赛博词只许用路人秒懂的，禁术语堆叠禁生造缩写（L5 说人话底线不降）。
- **声线**=本地赛博后处理链三档（`src/render/emotive_tts.py --cyber light|mid|full`·压平音高+机械颤音+位深压碎+频带+金属回声·全时长保持型不破字幕轴）；**产线定档=light**（CEO 2026-09-23 22:0X 拣音点选·O-20260923-2136-bm-a·v9 放行候选实证）——mid=对照档（机检推荐位）·full=极端参考端（ASR 实测伤事实词，禁量产）。
- **诚实律同构**：机器自述=AIGC 最诚实声明（「你正在看的这条视频，就是我剪的」）；一切「检测到/留底」只许报真实事实——系统日志体禁编造日志。
- 级别：L2 机制（T2·7 天否决窗）；上线后档位与语体热度由 M6 数据回流校准。

## §2.7 人味律 L15-L17（v1.3 · O-20260923-2210-bm-a「从底层要去ai感觉」触发 · 规格=human-feel-spec.md）

铁律趣律管「讲得对讲得有意思」，人味律管「不像机器做的」：

| # | 人味律 | 自检问句 |
|---|---|---|
| L15 | 参差与空气 | 句子长短有参差吗（句长 CV≥0.15 机检参考线）？**拍稿预算含空气预算了吗**（60s 视频文本 ≤55s·呼吸间隙不靠压缩换时长）？ |
| L16 | 禁完美对称 | 逐拍结构全对称吗（AI 排比指纹）？有没有一处破格（短句/转折/插入语）？ |
| L17 | 口语碎片配额 | 叙述者态别语气词配额用了吗（机器态 1-2 个/60s·本人态不限）？零语气词=提示 |

机检面=「copy-uniform」（`src/ai_feel_check.py`·WARN 级）；四站全机制规格=`docs/human-feel-spec.md`（配音/文案/画面/音频+M4 层 1.6 机检门）。

## §2.8 措辞简单易懂律（v1.4 · P-2026-09-26-11 CEO 令「措辞简单易懂」触发 · 证据=docs/audits/2026-09-26-program-quality-audit.md §4）

铁律趣律管「讲得对讲得有意思」，人味律管「不像机器做的」，本节管「第一次看的普通市民观众听得懂」——内部黑话零白话释义直出口播=audit 实证弱点（本令主承重维）：

| # | 措辞律 | 自检问句 |
|---|---|---|
| L18 | 概念词白话配额 | 每个内部黑话词（词表见下）首次出现，同拍或下一拍内配了具体场景或一句白话释义吗？ |
| L19 | 一句话说得清 | 随机抽一拍向不懂本司运营的市民复述——他能一句话说清这拍在讲什么吗？标题禁术语化（未释义内部缩写/黑话不得进标题）？ |
| L20 | 场景先行 | 抽象名词（协作/机制/体系类）前面有具体的人/画面/数字支撑吗？（E4「概念堆砌」三现旗 BS-002/BS-003 b3b6/BS-004 b7 的正面律） |

- **两律并存裁定（本节核心）**：系统日志体（§2.6·CEO 定档 O-2136·风格层）× 简单易懂（本节·理解层）**不冲突、分层立法**——叙述框架保持机器叙述者系统日志体不动；理解层加规=概念词首现即释义（「机器说话」≠「说黑话」）；有声线 v3 三轴定靶（CEO 亲校）=两律并存已达标实证样本。
- **适用面分层**：视频线/有声线口播+字幕+标题=全检；**L-卡卡面=档案 verbatim 来源律锁死不改卡面字**（MC-003 族信条语境旗吸收位=图文页语境+系列语境非卡面），本节在 L-卡线落点=M5 图文页语境层；M5 图文页=白话释义层主落点。
- **内部黑话词表（初版 12 词=audit §4.1 实证集）**：认领/回执/台账/循环/机队/门禁/工牌/离线判定/基线/回测/夏普/GATE——机读单一真相=`data/pipeline/jargon-terms.txt`（增词=本节变更记录+词表同步）。
- **机检判据（引擎=`src/plain_language_check.py`·M1 产稿即检·S2 随件复跑）**：①标题黑话命中=FAIL 级；②口播/字幕黑话命中逐词列报（首现行号+次数·首现是否配释义=人审/S1 裁决面——机器列报不判死）；③长难句=去标点 >40 字或逗号 ≥3=WARN；④S1 评审旗面扩展=L18-L20（违律扣分制·§2.6 白名单词=合规基线不旗）。
- 与 L5 说人话关系：L5 管机制词配人话翻译（前身），本节扩为内部黑话+抽象名词+标题三面并给可机检判据——L5 底线不降。

## §3 落地流程

1. **M1 产稿即自检**：稿件尾部附「铁律自检表」（L1-L8 逐条 ✓/✗+整改）——缺自检表=草案未完成。
2. **M4 复核**：lint 结构检查照旧；铁律语义项=Qiqi/CEO 人审面（抽样）。
3. **M6 校准**：上线后周复盘对 H1-H8 逐条出数据 verdict；连续两期证伪的假设=降级或改写（research 件 §2 表升级版本）。
4. **反吹嘘条款**：本铁律自身也是假设——**禁止拿未校准的铁律当不可质疑的教条**；被数据打脸即改。

## §4 与既有法的关系

- 宪法红线（不标题党/无来源不发布/不优化成瘾）**优先于**铁律——钩子不得承诺内容交付不了的。
- 与 persona-jason.md 口径叠加：出镜=Jason 本人第一人称；铁律管「怎么讲」，人设管「谁在讲」。
