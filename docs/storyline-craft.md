# BigStream 故事线爆款工艺（Storyline Craft）

> CEO 令 O-20260925-1720-bm-a「你写这些东西，一定要先去调研，要大众喜闻乐见的。要有爆款潜质的，好好想想」——视频线工艺资产向文字/图像/音频三介质的移植立制。
> 证据底座=`research/storyline-virality-research-v1.md` v1.0（§1 既有正典复引=本件法源主体；三线市场模式=通识级·账号期核验）。
> 级别：L2 机制（T2·7 天否决窗）。适用面：三线一切产出（网文/有声文本/漫画脚本与字幕带），产稿即检，M4 复核——与 copy-craft 同节律。
> 一句话总纲：**素材可以纪实，叙事必须爆款——同一座城，讲法两种命。**

## §0 病根（§3 终诊原文·防复发）

五篇初稿=散文纪录片：氛围开场、零冲突、零爽点、金句靠天收——与视频线「汇报工作不在讲故事」同病。**底料全是爆款原料（作死赌局/翻车实录/反差奇观），是工艺问题不是题材问题。**

## §1 文字线爆款铁律 T1-T9（每条=可检假设·上线后 M6 校准）

| # | 铁律 | 自检问句 |
|---|---|---|
| T1 | **黄金百字**（H1 移植） | 前 100 字有没有冲突/反差/悬念？删掉时间顺叙铺垫了吗？最炸的事实放第一句了吗？ |
| T2 | **赌局骨架**（P1 移植） | 本章的赌注是什么（时间/成败/人心/一笔账）？读者第 200 字前知道「赌什么」了吗？ |
| T3 | **冲突密度** | 有没有至少一个对抗（人 vs 难题/人 vs 人/城 vs 事故）？无冲突章=废章 |
| T4 | **爽点节拍**（H4 移植） | 每 300-500 字有没有一个 payoff（打脸/奇观揭示/翻车反转/温情爆点）？ |
| T5 | **金句配额**（P4 移植） | 全章有没有 ≥2 个可截图传播位？有没有一个评论区可接的钩（站队/接梗/投票）？ |
| T6 | **当事人感**（P5 移植） | 冲突是不是压在具体人物身上扛？禁纯氛围散文段 >80 字 |
| T7 | **卧槽位**（反差奇观） | 本章有没有至少一个「反差奇观」让路人停手（一人管一城/机器给人类发工资/432 说废就废）？ |
| T8 | **章尾冲突钩** | 章尾钩=下一章的**具体冲突预告**（禁「下一个人是……」式预告） |
| T9 | **真实瑕疵=爽点**（P7 移植） | 真实翻车有没有放进结构位（自纠案/返工/事故实录）？纪实线的爆点来源=真事故 |

红线不降：T1-T9 全部不得违背「不标题党」（钩子承诺正文必须兑现）+ 虚实边界律（charter §2）+ 来源清单（纪实线）。

## §1.5 赛博语体律（v1.1·O-20260925-1756 CEO 风格校准令——与 T1-T9 并列的硬门）

**骨架大众化、皮相赛博化、基底现实化**——三轴缺一即俗或缺闷。

1. **正典映射**（法源全在库）：
   - FluxVerse 三层构成（CEO 定位正典 2026-09-23）：骨架=真实地理与事实 / 血肉=真实实况 / **皮相=赛博未来风**——文字面=语体就是皮相；
   - BigLife 赛博后身律（CODEX §四）：「基于生活而高于生活·灵魂不变工具升维」——CEO 原话级公式；
   - copy-craft §2.6 词汇白名单律：赛博词只许路人秒懂（L5 说人话底线不降·禁术语堆叠禁生造缩写）。
2. **事实性赛博意象优先律**：这座城的光、流、扫描、门禁、年轮、LED、塔顶白光**都是真实存在**——写它们不是修辞，是纪实。「高于现实」靠把真实机制写精确，**禁靠形容词堆叠造未来感**（虚饰未来感=另一种俗）。
3. **禁俗词表**（土味爽文词禁入正文）：发疯/枪毙/卧槽/绝了/老铁/杀疯了/燃爆/封神/打脸（口语用法）——同义概念一律换系统语域（驳回/下线/全灭/清洗/封存/审计在案）。
4. **语域标尺**：系统日志体的文学化——冷面+精确+克制发光（赛博 light 档的文字版：微光晕可以有，霓虹满屏禁）。
5. **语体自检三问**（随件自检表增行）：①每个赛博词是不是城市里真有的东西？②删掉所有形容词后事实还立不立得住？③任意一句放进 CityWatch 界面违和吗（违和=语体跑偏）？

## §2 漫画适配 C1-C3

- **C1 尾格 PUNCH**：第四格=反转/金句/情绪爆点（禁平收）；单格可截图独立成立（截图传播性=第一指标）；
- **C2 字幕带=梗位**：主句一句扛（T5 金句待遇），副句=接梗钩/冷知识，禁图解式说明文；
- **C3 反差前置**：标题带即钩（「全城唯一……」句式=万能反差引擎）。

## §3 有声适配 A1-A2

- **A1 前 30 秒定留存**：继承 T1 黄金百字——演播稿首 30 秒必须是钩（禁片头寒暄/背景介绍）；
- **A2 单集完整钩+悬念尾**：每集一个完整小赌局+下一集具体冲突预告（T8）。

## §4 与流程/评审接线

- 产稿即自检：稿件尾部附「爆款自检表」（T1-T9 逐条 ✓/✗+整改）——缺表=草案未完成（copy-craft §3 同制）；
- M4 复核：T1/T2/T3/T8=硬门（✗=不过）；T4-T7=抽审；红线五条+三重标注照旧前置；
- E-席评审：文字线终审增「大众面」打分维（对照本件 T1-T9）；
- M6 校准：上线后按章评/完读/转发数据逐条 verdict；证伪即改（反吹嘘条款：本件也是假设）。
