## §3 AI 赋能运行原则

1. **SOP 机器可执行优先**：能写进 lint/探针/模板/脚本的纪律，不靠自觉——规则必须长出牙齿（M4 门禁即先例）。
2. **一岗多会话**：任何 AI 会话（交互或 OS 循环轮次）按辖区自认领部门职责；认领即负责，干完写账；部门负责人=职能身份，非拟人（同「记录员」原则）。
3. **人类只握决策与终审**：CEO=决策面，Qiqi=人文终审面；其余运转全 AI，无人值守。
4. **产出即证据**：部门工件全部落 git；无 commit 的产出视为未发生。
5. **辖区纪律**：跨部门协作=流程段衔接（M0→M6）；只改本部门辖区目录，改他部辖区先提案。
6. **辖区=评审职责**（O-20260923-2245-bm-a）：各部门对辖区产出的质量负专家门责任——环节席 S0-S6 与门槛见 `docs/dept-review-mechanism.md`（引用不复制）；环节门台账=`docs/reviews/station-reviews.md`。
