## §1 判据（预注册·三律）

| # | 律 | 判定（机检面=工具化项） | FAIL 处置 |
|---|---|---|---|
| J1 保真律 | 摘要零新增断言；数字与原文逐字一致；每个要点带 [L行号] 来源引用 | 机检：引用行号 ≤ 原文行数且**引用数 ≥3**（地板=防「全文一枚引用」退化件·R307 run2 实证锁）；数字逐字一致=人工抽检面（抽 3 个数字回原文核对） | 该件降级=不替代人工读取（原文照读·advisory 边界） |
| J2 覆盖律 | 结构三段式（一句话结论/要点/卡点与未决）+行数帽 ≤60 行+原文节标题全覆盖 | 机检：行数帽+分节头在场；节标题覆盖=人工抽检面 | 同上 |
| J3 效率律 | 本地零 API token；单件 ≤10min（7b 档默认·14b 档=难件可选） | 机检：duration+模型名记录在验证声明 | 超时=如实记录不恋战（工具 exit 3） |

- 判定口径：三律全过=P4 件 PASS；任一 FAIL=该件如实入账降级（原文照读），管线本身不因单件 FAIL 而废——每批按「本地处理 N 件·云端省减 M 读取轮次」记账（台账见 §2）。
- 输入帽：单件输入 >6000 字符=按头 6000 字符截断并在验证声明声明（7b ctx 预算·诚实截断非静默丢尾）；更大件=14b 档或分批（后续升格面）。
- 台账口径：`data/pipeline/p4-ledger.md` 行级追加（时间/输入件/模型/摘要件/行数/引用/截断/时长/判定）——10-07 治理日替代率首报的数据面（周轮汇 L2/(L2+L3)）。
