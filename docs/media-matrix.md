# BigStream 媒体矩阵顶层机制（Media Matrix）

> CEO 令 2026-09-23（O-20260923-1512-bm-a）：「建立顶层机制，并把主流平台覆盖，媒体矩阵」。
> 本文件=矩阵总纲：分层、角色、流转、批次、合规、扩容。单平台策略细节=`docs/platform-playbook.md`；账号台账=`docs/accounts.md`；生产流转=`docs/content-pipeline.md`。

## §1 矩阵总图（11 平台 · 四层）

| 层 | 平台 | 角色 |
|---|---|---|
| **L1 引流层**（竖版短内容） | 微信视频号 · 抖音 · 快手 · TikTok（海外） | 3 秒钩子获客，把流量导向沉淀层 |
| **L2 纵深层**（中长视频） | B站 · YouTube（含 Shorts） | 知识区纵深，建立专业信任，长尾复利 |
| **L3 沉淀层**（图文长文） | 微信公众号 · 知乎 · 今日头条 | 深度长文主阵地，搜索长尾 |
| **L4 扩散层**（社交短文/图文） | 新浪微博 · 小红书 | 热点卡位、社交裂变、话题扩散 |

内容流转：L1 引流 → L3 沉淀（一稿多变体）→ L4 扩散；L2 双语线独立长跑。

## §2 一稿多变体 SOP（引用 content-pipeline M3）

同一选题默认产出：

1. **竖版 60s 口播稿**——视频号/抖音/快手/TikTok 共用骨架，各按平台改钩子与话术；
2. **长文**——公众号全文 → 知乎/今日头条同源多发，各按社区格式裁剪；
3. **中长视频脚本**——B站/YouTube（中英双语字幕）；
4. **社交短文+图卡**——微博/小红书（内容长图由图文母稿派生）。

变体登记在草稿头部（母稿链接）；一人成本，矩阵分发。

## §7 直播线合规注记（慢直播·2026-09-27 周日轮立法）

> 立法源=集团 P-20260924-62 ⑥ T2 立法候选⑦「慢直播合规注记」（Z6·决策轮不越权立法·decision.md §5 周日周轮落法·backlog #21）+ D-20260924-08 直播同号拍板 + 技术底座正典 `cph4/research/R-20260924-infra-5-stream.md`（跨仓只读引用）。本节=直播线预注册合规约束——直播线本体=blocked-on-CEO（#17 [needs-CEO] 提案在板），激活前置=账号物理件+BigCompute 开播执行面就位；未上线=未测量。

- **分工口径（D-08）**：每平台唯一账号=本司资产面（accounts.md 同号口径注记在案·R150）；**开播执行=BigCompute 直播运营部**；本司份额=账号管号+直播内容策略+直播合规面。
- **开播策略以 BigCompute 风控为准**（Z6 本体）：无人值守挂播平台风险对齐 BigCompute risk-register E1；本司不自设开播节奏/通道开关，开播窗口须与集团 GPU 车道协商（fleet §10 verdict 驱动）。
- **慢直播/24h 无人编排=政策高危面**（P3·CEO 单独立项前置）：抖音通道默认关=设计结论（健康分制度 2024-01-03+2026 全平台无人直播新规）；视频号带货域虚拟直播=违规（2024-06 低质量内容细则），非带货域开播前逐平台人工复核现行规则；B站先行试点（相对宽容·生态经验观察非官方明文）。**开播前逐平台复核现行规则=硬前置**（平台规则变动频繁）。
- **直播画面 AIGC 标识义务**（P-40 升格全呈现面律）：直播画面=AI 生成像素城——依《人工智能生成合成内容标识办法》（2025-09-01 施行）直播间标题/简介显著标注+画面角标常驻（CONSTITUTION 红线同源·全呈现面零例外）。
- **发布锚律**（versioning §3.4）：每次开播所用 City build+推流配置可定位唯一 commit（tag 写入直播间简介=对外可追溯）。
- **账号域红线**：注册/实名/认证/推流权限申请/B站直播开放平台入驻=CEO 物理件（AI 永不代办·密钥只进 .env）。
