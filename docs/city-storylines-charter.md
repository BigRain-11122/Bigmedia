## §0 一句话

**城市每天真实发生的事，就是写不完的书。** 三条线（网文/有声/漫画+扩容位）共用一个素材主权（硅基城市实况），一个合规底座（三重标注），三套管线。

## §2 虚实边界律（正典·一切件适用）

1. **纪实线**：城市真实事件/年轮/编年史的叙事化改编——禁虚构添加·每篇带来源清单（git/台账/年轮指针）·标注「基于硅基城市真实事件」。
2. **创作线**：虚构故事——必带「本故事为虚构创作·基于硅基城市设定」声明·不冒充实录·禁给真实居民年轮层伪造未发生事实（年轮=事实账·小说=创作账·两账永分离）。
3. **三重标注**=虚实级+来源级（纪实线）+AIGC 级——缺一不过 M4。
4. **人设权红线**：荣誉席三卡（大圣/Qiqi/Rain）只引已登记设定禁新增人格；避讳律照 CODEX §五（禁真实人物名/公众人物名/正典实锚人设名）；纯白视觉=CEO 专属（漫画线照 CODEX §七）。

## §3 选题律

- **选题池双源**：①编年史源（集团 git 史+令牌台账+城市事件流=纪实线）②居民源（万人卡钩子字段×派系×思想六轴×认知层情绪/谣言链=单元剧）——选题研究部按 M0 流程纳管，每题带素材指针。
- **一题三态**：同一素材=网文稿→有声稿（同文本 TTS）→漫画脚本（钩子视觉化）——反重复铁律：一料多吃·禁重复创作。

## §4 路径与命名

```
data/storylines/
├── novel/    # 网文稿：SC-<号>-<章>-v<版本>.md
├── audio/    # 有声稿与音频产物台账（mp4/mp3 gitignored·README 记账）
├── comic/    # 漫画脚本与分镜：SC-<号>-话-v<版本>.md
└── cards/    # 图文卡（L-卡）：MC-<YYYYMMDD>-<形态码>-v<版本>（PNG 成品入 git+README 记账；渲染 mp4 副产不入本目录）
```
- 系列号 SC-XXX 全线统一（SC-001《硅基城市编年史》）；产出件一律带三重标注块（§2）。
- L-卡 形态码：QUOTE=金句语录卡 / DAILY=城市日签 / CENSUS=居民卡图鉴 / DIGEST=盘点图文 / REACT=热点城市反应版；成品登记=`output/finished.md`（F 系号续用·线别入备注）；发布物=schedule.md。

## §5 门禁映射（M4 三线适配·红线不降）

| 检 | 网文 | 有声 | 漫画 | 图文卡（L-卡） |
|---|---|---|---|---|
| 红线五条 | ✓ | ✓ | ✓ | ✓ |
| 三重标注 | ✓（文首） | ✓（说明+音频内置） | ✓（图内角标+简介） | ✓（AIGC 图内角标=引擎烧录+虚实级/来源级图内小字行） |
| 来源完备 | 纪实线必附 | 继承文本 | 继承脚本 | 池/卡/编年史指针（图内署名行+README 台账双落） |
| 机检 | draft_lint 扩展（后置·先人审） | S2 三门照跑 | 图像抽验（PoC 后立制） | 静态卡抽验（M1 PoC 后立制·先人审） |
| **爆款工艺**（storyline-craft §4·O-20260925-1720 起） | **T1-T9 自检表随件**（T1/T2/T3/T8=硬门·✗=不过 M4） | 继承文本+演播钩（A1/A2） | 脚本与字幕带过 C1-C3（尾格 PUNCH/字幕=梗位/反差前置） | 标题带即钩=反差前置（C3 同律） |

**自动化合规上限**（O-1327 新线专属·M4 追加检）：自动化≠裸量产——每件须带编辑价值（轴级署名/情境标注/叙事包装·公众号低创作度条款 7.1-7.4 A 级）；缺编辑价值=M4 不过。
