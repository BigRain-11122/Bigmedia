## §0 一句话

**城市每天真实发生的事，就是写不完的书。** 三条线（网文/有声/漫画+扩容位）共用一个素材主权（硅基城市实况），一个合规底座（三重标注），三套管线。

## §1 条线编制

| 线 | 载体 | 首发阵地 | 产能归属 |
|---|---|---|---|
| L-文 网文线 | 连载小说（纪实《硅基城市编年史》主线+创作线预留） | 公众号连载（批次①·零新账号）→外部平台（账号期政策核验后扩） | 会话撰稿（AI 起草+人审定稿）+循环排版发布 |
| L-音 有声线 | 有声小说/播客（编年史有声版首启） | 公众号/视频号音频帖（批次①）→喜马拉雅系（账号期） | 循环既有 TTS 链（`--cyber light`+`--human`·机器叙述者=城市自述视角） |
| L-画 漫画线 | 条漫单元剧《硅基居民卡》 | 公众号图文（批次①）→快看/微博/小红书（批次②③） | 云图像生成通道（PoC 定栈）+人设对齐抽验 |
| 扩容位 | 「等一系列」：广播剧/设定集/图鉴/互动小说——按条线架构追加 | — | 新条线=走本章程 §6 新线流程 |

**编制纪律**：三线不设新部门——走既有七部一办（选题研究部供选题/内容生产部产稿/工程技术部渲染/合规审查部过门/平台运营部发布）·P-62 精简原则不回胀。

## §2 虚实边界律（正典·一切件适用）

1. **纪实线**：城市真实事件/年轮/编年史的叙事化改编——禁虚构添加·每篇带来源清单（git/台账/年轮指针）·标注「基于硅基城市真实事件」。
2. **创作线**：虚构故事——必带「本故事为虚构创作·基于硅基城市设定」声明·不冒充实录·禁给真实居民年轮层伪造未发生事实（年轮=事实账·小说=创作账·两账永分离）。
3. **三重标注**=虚实级+来源级（纪实线）+AIGC 级——缺一不过 M4。
4. **人设权红线**：荣誉席三卡（大圣/Qiqi/Rain）只引已登记设定禁新增人格；避讳律照 CODEX §五（禁真实人物名/公众人物名/正典实锚人设名）；纯白视觉=CEO 专属（漫画线照 CODEX §七）。

## §3 选题律

- **选题池双源**：①编年史源（集团 git 史+令牌台账+城市事件流=纪实线）②居民源（万人卡钩子字段×派系×思想六轴×认知层情绪/谣言链=单元剧）——选题研究部按 M0 流程纳管，每题带素材指针。
- **一题三态**：同一素材=网文稿→有声稿（同文本 TTS）→漫画脚本（钩子视觉化）——反重复铁律：一料多吃·禁重复创作。

## §4 路径与命名

```
data/storylines/
├── novel/    # 网文稿：SC-<号>-<章>-v<版本>.md
├── audio/    # 有声稿与音频产物台账（mp4/mp3 gitignored·README 记账）
└── comic/    # 漫画脚本与分镜：SC-<号>-话-v<版本>.md
```
- 系列号 SC-XXX 全线统一（SC-001《硅基城市编年史》）；产出件一律带三重标注块（§2）。
- 成品登记=`output/finished.md`（F 系号续用·线别入备注）；发布物=schedule.md。

## §5 门禁映射（M4 三线适配·红线不降）

| 检 | 网文 | 有声 | 漫画 |
|---|---|---|---|
| 红线五条 | ✓ | ✓ | ✓ |
| 三重标注 | ✓（文首） | ✓（说明+音频内置） | ✓（图内角标+简介） |
| 来源完备 | 纪实线必附 | 继承文本 | 继承脚本 |
| 机检 | draft_lint 扩展（后置·先人审） | S2 三门照跑 | 图像抽验（PoC 后立制） |

## §6 新线流程（「等一系列」扩容位）

新条线三步：①调研件（research/ 增版·素材面复用本章程）②本章程 §1 表增行（T2）③首件 PoC 过 §5 门禁——禁无 PoC 立线。
