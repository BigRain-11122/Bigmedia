## §2 虚实边界律（正典·一切件适用）

1. **纪实线**：城市真实事件/年轮/编年史的叙事化改编——禁虚构添加·每篇带来源清单（git/台账/年轮指针）·标注「基于硅基城市真实事件」。
2. **创作线**：虚构故事——必带「本故事为虚构创作·基于硅基城市设定」声明·不冒充实录·禁给真实居民年轮层伪造未发生事实（年轮=事实账·小说=创作账·两账永分离）。
3. **三重标注**=虚实级+来源级（纪实线）+AIGC 级——缺一不过 M4。
4. **人设权红线**：荣誉席三卡（大圣/Qiqi/Rain）只引已登记设定禁新增人格；避讳律照 CODEX §五（禁真实人物名/公众人物名/正典实锚人设名）；纯白视觉=CEO 专属（漫画线照 CODEX §七）。

## §3 选题律

- **选题池双源**：①编年史源（集团 git 史+令牌台账+城市事件流=纪实线）②居民源（万人卡钩子字段×派系×思想六轴×认知层情绪/谣言链=单元剧）——选题研究部按 M0 流程纳管，每题带素材指针；**③codex 源（2026-09-28 起·O-20260928-1910）**=`data/storylines/codex/` 五维正典（历史/文化/精神/人文/居民群像志）=三线选题的第一素材面（叙事文化层·BigStream 总责）。
- **一题三态**：同一素材=网文稿→有声稿（同文本 TTS）→漫画脚本（钩子视觉化）——反重复铁律：一料多吃·禁重复创作。
- **融汇面判据（2026-09-28 起·O-20260928-1411-HQ-C·主干件 cph4/research/R-20260928-city-fusion.md 本司三腿）**：城叙事引入古今中外典故/节庆/异文化元素须过混汇三问（入城因果链 M1/叠加点位 M2/三流功能解释 M6·禁贴皮 N5·禁国别直译 N1/N7）且带普世原型与共享母题场景（M11/M12·高抽象仅氛围层 N6）——口吻五律+母题清单+八锚+美感同族律（内容物料美术语汇与城美术底一套日漫风同族·M9/M15）全表=`docs/research/R-20260928-bigstream-05-city-fusion-narrative.md`。

## §4 路径与命名

```
data/storylines/
├── novel/    # 网文稿：SC-<号>-<章>-v<版本>.md
├── audio/    # 有声稿与音频产物台账（mp4/mp3 gitignored·README 记账）
├── comic/    # 漫画脚本与分镜：SC-<号>-话-v<版本>.md

├── drama/    # L-剧 剧线（2026-10-08）：SC-<号>-<集>-v<版本>（剧本+分镜表 JSON+参照卡指针+成片 README 记账·mp4 gitignored）

```
- 系列号 SC-XXX 全线统一（SC-001《硅基城市编年史》）；产出件一律带三重标注块（§2）。
- L-卡 形态码：QUOTE=金句语录卡 / DAILY=城市日签 / CENSUS=居民卡图鉴 / DIGEST=盘点图文 / REACT=热点城市反应版；成品登记=`output/finished.md`（F 系号续用·线别入备注）；发布物=schedule.md。
