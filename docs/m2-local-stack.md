## §2 显存分时策略（多公司共机纪律）

- 本机 Ollama 常驻 8.6GB（BigMoney/集团共享）——渲染任务执行前查 `nvidia-smi` 空闲位：
  - 空闲 ≥6GB → 可跑 SDXL 级（后置）；
  - 空闲 3-4GB → STT/TTS 后处理/字幕（faster-whisper small 档）照常；
  - 空闲不足 → 暂停（keepwarm.pause 同源礼仪），排队，**禁强杀他人常驻进程**（集团共享机纪律 governance §6）。
- 媒体线任务=非紧急批处理，让位优先级最高的是量化公司盘中任务。

## §3 兜底报批规则（P1 级）

本地不满足才走云/付费（如高质量配音克隆、商业图库），**逐单报批**：需求+三家比价+预期收益 → CEO 署名。零预算原则不动。

## §4 PoC 阶梯（backlog 驱动·循环可执行）

1. **R-A** 口播→成品最小闭环 PoC：`src/render/` 落一个 FFmpeg 时间线脚本——输入=口播 txt + SRT + 字卡模板 → 输出=9:16 mp4（黑底白字卡版 BS-001 60s 口播）——**纯本地·零安装**。
2. **R-B** edge-tts 三案音色参数表（A/B/C 各一档试录样件落 `data/sources/tts-samples/`）+ Piper 本地替代 PoC（装/测/对比，为去云依赖备份）。
3. **R-C** faster-whisper 字幕对轴脚本（口播 wav → SRT → 硬字幕合成入 R-A 流水）。
4. **R-D** （后置）ComfyUI 安装评估报告——仅在首发数据证明需要 AIGC 画面时提请。

## §5 红线（不变）

素材来源可溯（`data/sources/`）；画面/字幕脱敏审（M4）；AIGC 依法显著标识（字幕声明+平台开关双落）；量化内容附非投资建议。
