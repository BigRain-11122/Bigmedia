# BigStream 素材对位工作流规格（Footage-Matching Spec）

> 溯源：CEO 反馈 2026-09-24 16:4X「录制的内容也和说辞文案完全不匹配，反思工作流，建立正确严谨专业的工作流」。
> 定位：**M1→M2→M3 的对位正典**——修复「素材先有·文案后贴·单一录屏循环当万能底版」的倒挂流程。与 editing-craft-spec（剪法）互补：对位=「这一拍该看什么」，剪法=「这一拍怎么剪」。
> 级别：T2 机制（7 天否决窗）。判据=机器可验面；语义对位=抽帧验图（评审面）。

## §0 一句话

**拍什么说什么：每拍的画面必须是那一拍内容的证据——素材不是壁纸，是证词。**

## §1 分镜对位律（shot plan 先于采集）

- 文案/拍稿定稿后、素材采集前，先出**分镜对位表**：cards.json 每拍增 `visual` 字段——
  - `"source": "<素材文件指针>"`（竖版预处理件·`data/sources/footage/*-vertical.mp4`）
  - `"req": "<这一拍画面必须可见什么·一句话>"`
  - `"cards-only": true` + `"reason"`（明示纯字卡拍·禁默省）
- **无对位表的稿=禁入 M2/M3**（S3 变体官门拦·draft_lint 层挂声明完备检查）。

## §2 采集律（拍什么录什么）

- **逐镜采集**：`record_screen.py` 站按表开窗-录-即关（静默律例外沿 O-1115 惯例·录毕即关）；一镜一文件·命名 `<主题>-raw.mp4`。
- **规格化预处理**：`prep_vertical.py` blur-pad 竖版化（1080×1920·横素材模糊衬底+原比例贴中）——所有素材进 R-E 前统一规格。
- **脱敏前置扫描**：采集前扫目标界面（K线/持仓/密钥/token 用量=禁入素材·宪法脱敏律）；**必须扫「渲染后探针帧」——源码关键词扫描不够**（2026-09-24 实证：BigMoney 总控 HTML 源码零敏感词，渲染探针帧现持仓数/净值/策略师盈亏=JS 数据填充→该镜判敏感禁用换公司小镇面）。
- **前台置顶律**：gdigrab 录的是桌面区域非窗口——采集站必须先 `focus_window` 置顶（2026-09-24 实证：CityWatch/机队监控两镜录穿了桌面上的 Unity 编辑器）。
- **活动桌面律**（2026-09-24 二实证）：置顶也不保证——机队监控/公司小镇两镜连续录穿成**桌面上正开着的第三方聊天窗口（隐私面，素材当场作废删除）**。①录后必须探针帧验证目标窗口真在前台，验证不过=作废删除+换源；②CEO 活跃用机时段优先**复用既有合规素材**（反重复铁律同源），不反复弹窗打扰。
- 素材层归档=`data/sources/footage/`（R2 源资产位·retention 同律）。

## §3 选镜律（按表剪辑）

- R-E 剪辑站**逐拍绑定自己的素材文件**（`visual.source`→plan 每段 `visual_source`）；短素材段内循环合法（禁重复同窗当万能底版——一拍一源是底线）。
- **cards-only 拍须声明理由**（CTA/口号拍常规）；**对位率**（有匹配素材拍数/总拍数）≥80%=进链件线；测试件如实记录不硬凑。
- 同源多用合法但须在对位表注明（如 CityWatch 服务开场/回环拍）。

## §4 对位机检（edit_craft_check 对位面·M4 层 1.8 扩展）

- 机器可验：①`visual` 声明完备 100%（缺=FAIL）②声明的素材文件存在（缺=FAIL）③cards-only 无理由=FAIL ④对位率算给出门（≥80% 进链·测试件 WARN 如实）。
- **语义对位**（画面内容是否真匹配文案）机器不装懂：抽帧验图面（会话/评审）。
- **验图采样面三律**（R186/R189/R196 三案教训·#26 立法）：每拍抽样必含——
  1. **拍头一帧**：核对 `req`（画面声明对位）；
  2. **段中/尾帧**：长拍录穿面（R186 立法：citywatch 源尾录穿豆包聊天窗·历轮只验拍头=段中尾从未被测的假绿灯第一案）；
  3. **回环边界帧**：拍时长 > 源长时（`stream_loop` 回环穿越），**beat 相对=(源长−src_off) 处 ±0.1s 必采**（穿越点=源尾帧回绕源首帧的过渡位；R196 假绿灯第二案：裁剪线含 10 帧脏尾·8 拍污染全落此区间而段中尾采样未覆盖 beat 相对 4.03-4.4s 穿越区）。
  全部过验才算修复实证——采样面缺一=未测面宣称（假绿灯律① 追加制适用于验图面）。
- 假教训在案：live-A 用「Biggame 游戏公司一块屏」配「三家公司开张」全片=对位 0/12——观众一眼识破声画两张皮（CEO 2026-09-24 点名）。

## §5 工作流正典（顺序·专业版）

```
文案定稿(M1) → 分镜对位表(§1) → 逐镜采集+预处理+脱敏扫描(§2·M2)
→ R-E 对位剪辑(§3·M3) → 三门机检+对位面(§4·M4 层1.8) → 抽帧验图(语义对位) → 评审团
```

旧流（素材先有→文案后贴→循环当底版）=本规格废止对象；禁止再产「素材壁纸件」。
