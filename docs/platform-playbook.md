## 平台一览

| 平台 | 主形态 | 画幅/时长 | 发布通道现实 | 冷启定位 |
|---|---|---|---|---|
| 微信视频号 | 短视频 | 9:16 · 30-60s | 无公开 API：网页版草稿箱/手动 | 微信生态社交裂变，集团私域入口 |
| 微信公众号 | 图文/长文 | 竖版图文 | **有草稿 API**（公众平台素材接口，需 AppID+Secret=物理件） | 深度内容沉淀、搜索长尾 |
| B站 | 中长视频 | 16:9 · 3-15min | 无公开发布 API：创作中心手动/半自动 | 知识区纵深、年轻用户、弹幕反馈 |
| YouTube | 中长+Shorts | 16:9 / 9:16 | **Data API 可用**（OAuth=物理件） | 海外+长尾复利，慢热长跑 |
| 新浪微博 | 短文/图文 | 混合 | 开放平台 API 有限，多为手动 | 热点扩散、话题卡位 |

## 各平台策略要点

- **视频号**：钩子前 3 秒；社交推荐权重高——每条视频配一句「转给XX」话术；与公众号联动（视频号可挂公众号文章）。
- **公众号**：主赛道深度长文的主阵地；标题=搜索词+利益点双写；AI 生成图当封面须过 M4 门。
- **B站**：知识区「AI 如何无人值守开公司」系列天然对口；封面标题三件套决定 CTR；系列化栏目（栏目名待 CEO 点）。
- **YouTube**：中英双语字幕（海外线天然练手场）；Shorts 引流长视频；SEO 标题描述。
- **微博**：话题卡位+日更短打；正文钩子+图卡（内容长图由图文母稿派生）。

## AIGC 合规标识

- 中国境内平台：依《人工智能生成合成内容标识办法》显著标识 AI 生成（文案声明+平台标识开关双落）。
- YouTube：启用平台 AI disclosure 标记。
- 各平台规则变更时本册由 AI 复核更新，changelog 注明。
