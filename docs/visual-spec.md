# BigStream 视觉规范（Visual Spec）

> CEO 令 O-20260923-1937-bm-a（「字体构图什么的都很糟糕」→反省→立制）。
> 适用面：一切画面产出（字卡/字幕/封面/水印/界面实录剪辑）。发布前置=M4 视觉审（E7 席）。
> 级别：L2 机制。品牌锚=集团视觉律（极简黑白+大留白）——本规范是它的执行细则，不推翻基调，执行好它。

## §0 反省结论（为什么此前糟糕）

单一字重+全部居中+无层级+无构图=「终端审美」不是「内容设计」。观众第一眼看到的是**版式**，不是文字。

## §1 字重层级律（字体栈·本机实况库）

| 层级 | 用途 | 字体（本机路径） | 字号基准（1080×1920） |
|---|---|---|---|
| H1 锚点大字 | 数字/口号/关键词（一卡一锚） | **msyhbd.ttc 微软雅黑粗**（或思源宋 Heavy 点睛款） | 88-120 |
| H2 说明行 | 锚点下的补充行 | msyh.ttc 常规 | 52-64 |
| H3 弱化行 | 次要信息 | msyhl.ttc 细体 | 44-48 |
| SUB 字幕 | 口播字幕 | msyh.ttc | 44（既定） |
| NOTICE 合规带 | AIGC 标识 | msyhl.ttc 细体·灰白 60% | 30（既定） |

- **一卡最多一个 H1**；H1 永远最大，层级靠字重+字号双拉开（不许同字重凑数）。
- 中文数字优先用 H1（数字=最强锚点）；衬线 Heavy 仅用于「金句卡」单点强调，一视频 ≤2 次。

## §2 构图网格（9:16 版式系统）

- **安全边距**：左右 96px（≈8%）；上下安全区 250px（顶部 NOTICE 带下）/450px（底部字幕带上）。
- **视觉重心**：字卡主体中心 = 帧高 **42%**（人眼舒适区偏上；字幕固定底部——主体严禁压到 68% 以下）。
- **三段构图**（每张字卡）：H1 锚点 → 间距 24px → H2/H3 说明（≤2 行）——禁止整卡塞满；**留白即层级**。
- **对齐律**：H1 居中；H2/H3 与 H1 中心对齐；禁止左对齐混居中（此前病根之一）。
- **行数上限**：字卡正文 ≤4 行；超=拆卡（拆卡=节奏，不是负担）。

## §3 色彩律

- 基调：纯黑 `#000000` 背景+白 `#FFFFFF` 文字（集团黑白律不动）。
- **强调色系统**（新增）：唯一强调色=**FLUX 光点白金 `#E8E6DF`** 用于 H1 描边或数字锚点渐变；次强调=60% 灰 `#999999`（H3/NOTICE）。
- AIGC 标识带：灰白 60%（E7 审位置=左上恒定·不与 H1 抢视线）。

## §4 动态律（进出场）

- 字卡进场：150ms 淡入（不许硬切硬出）；退场同律。
- 一拍一卡=口播词边界（既定·1918 令）；换卡瞬间允许 4px 上移动效（克制）。
- 禁止花哨转场（缩放旋转滑入全部禁止——黑白极简=呼吸感，不是特效感）。

## §5 封面/首帧律

首帧 3 秒=封面级：H1 口号+黑底，**须过 E7**（首帧即点击率的根）。

## §4.5 赛博同步层（v1.1 · D-BS-03 委托决策自决·2026-09-24）

声面已定档赛博（O-2136 light 档+机器叙述者+系统日志体），画面面同律同步——三层**克制**增补（黑白极简基调不动·全部 2D 光效）：

1. **字卡发光描边**：H1 锚点字允许 FLUX 光点白金 `#E8E6DF` 微光晕描边（1-2px·克制档）——点睛非霓虹；一卡一锚律不变；禁整屏发光。
2. **AIGC 标识带机械体**：NOTICE 带升级 `[AIGC·AI 生成内容]` 方括号系统体——机器自述=最诚实声明的视觉面；显著性不减（位置/字号/灰白 60% 不动）。
3. **界面实录机械 UI 感**：实录底版可加单向细扫描线（透明度 ≤8%·禁盖字卡主体）+状态行细字（H3 档·如 `sys.beat=06 t=00:23`）——真实画面优先律不破，扫描线=氛围层非信息层。

判据：每件过 E7 席按本节审；渲染器参数（描边光晕/扫描线开关）随量产批次逐件启用（工程位入 backlog·件件可选开关）。

## §6 与流程/评审的接线

- M2/M3 增「视觉规格」检查点：分镜表「画面」列必须按本规范填（H1 锚点字+层级+构图位）；
- M4 工艺审核层增 **⑤视觉审**（按本规范逐条：字重层级/构图网格/色彩/动态）；
- 评审团 **E7 视觉设计官**入席（review-panel v1.2）：rubric=本规范 §1-§5；E7 <9=FAIL（视觉不合格不放行——补上今天暴露的盲区）。
