# BigStream 变体骨架模板（Variant Templates）

> 交付=backlog#2（CEO 令 O-20260923-1525-bm-a 底层优先阶段：模板=机制件非内容，不违反生产暂停令）。
> 引用不复制：分层/流转/批次=`docs/media-matrix.md`；单平台策略与通道现实=`docs/platform-playbook.md`；生产线 M3=`docs/content-pipeline.md`。本文件只存可填空的字段骨架。
> 纪律：易过期数字一律标「以平台现行规则为准」，恢复生产套用前须复核；标题承诺=内容交付（红线 1·不标题党）。
> 使用法：M3 恢复后，每平台复制 §3 对应骨架块填空 → 变体头登记块回填（§1）→ `python src/draft_lint.py` 0 FAIL → M4 GATE。

## §1 变体头登记块（每个变体文件首部必带）

```markdown
---
母稿= data/drafts/<母稿文件名>
选题号: BS-0XX
平台: <平台名>
栏目人设: <A 超体日志 / B AI 打工实录 / C 一人集团 ·待 CEO 点名>
实测时长或字数: <draft_lint 实测值>
AIGC 标识: 文案声明 + 平台标识开关（双落）
GATE: PENDING
---
```

## §2 四类母稿形态（media-matrix §2 同源·骨架映射）

| 形态 | 用途平台 | 共用规则 |
|---|---|---|
| V1 竖版 60s 口播 | 视频号 · 抖音 · 快手 · TikTok | 共用口播骨架，各平台只改钩子与话术 |
| V2 图文长文 | 公众号（母稿全文）→ 知乎/头条同源裁剪 | 一人成本，同源多发 |
| V3 中长视频脚本 | B站 · YouTube | YouTube 线中英双语字幕 |
| V4 社交短文+图卡 | 微博 · 小红书 | 图卡由图文母稿派生 |

## §3 平台骨架块（11 块·逐平台填空）

### 1. 微信视频号（L1 · V1）
| 字段 | 骨架规格 |
|---|---|
| 标题 | 主钩子一句话；承诺=内容交付（不标题党） |
| 画幅/时长 | 9:16 · 30-60s（口播约 220-240 字/60s，以 draft_lint 实测为准） |
| 结构 | 前 3 秒钩子 → 主体 → 结尾「转给XX」社交话术；可挂公众号文章（联动） |
| 标签 | 3-5 个话题标签（以平台现行规则为准） |
| 封面提示 | 竖版大字标题卡；AIGC 图须过 M4 |
| 合规标识 | 境内双落：文案声明 + 平台标识开关 |
| 通道 | 网页版草稿箱/手动（无公开 API·账号=CEO 物理件） |

## §4 套用检查单（M3 恢复后逐变体过）

- [ ] 变体头登记块齐全，母稿链接有效（§1）
- [ ] 标题承诺与内容一致（红线 1）
- [ ] 字数/时长以 draft_lint 实测为准，超规格先裁稿（参见 backlog #5 前车之鉴：4 稿 67-77s 超时）
- [ ] AIGC 标识双落（境内 9 平台）/ disclosure（YouTube）/ AI 标签（TikTok）
- [ ] 封面图来源可溯（`data/sources/`）
- [ ] 来源引用完备（红线 2·无来源不发布）
- [ ] 量化类内容附非投资建议声明（红线 7）
- [ ] GATE PENDING → PASS 后才流转 M5（发布前置硬门）
