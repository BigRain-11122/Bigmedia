# MV0001 修复面复核 R2417（v700 / v702 / v703 捕获时点定档·2026-10-24 00:3x）

执行体=BigStream-OSLoop。只读入料，只写本件与 state；未改在执 MV sprint 会话的任何渲染链或在产件。

## 〇、本轮相对 R2416 的两个纠错

1. **R2416「v700 最干净」不成立**：其 11 点清单只覆盖 44.00s（第 1056 帧），漏掉第 **1057 帧**——该帧是整镜闪帧（见 §二板图）。
2. **R2416「77.33s 残留 0.302 需肉眼定档」定档=非弹出**：该处 d1/d2/d3 仅 950/300/860（真切点在 300 万量级），比值高但绝对变化≈0.01 code/像素，是静态镜内的颗粒/火焰噪声，肉眼不可辨（板图 §三 前四格几乎逐帧相同，第 1858 帧才是真切点）。

## 一、方法（本轮工具化）

新增 `src/mv_pop_probe.py`：对给定时点取 N-1/N/N+1 三帧（240×136 rgb24）算

    outlier = (d1 + d2 - d3) / (d1 + d2),  d1=|fN-fN-1|, d2=|fN+1-fN|, d3=|fN+1-fN-1|

**并加绝对幅度门 `--min-abs`（默认 20000）**：比值高但 d1+d2 低于门的，判为不可见变化。
理由=77.33s 这一档反例：比值 0.28-0.31 却完全不可见，纯比值会给假阳性。

## 二、44.042s 闪帧（实际缺陷·肉眼确证）

捕获时点各件 d 值（rgb24 绝对差）：

| 件 | t=44.0 (f1056) | t=44.042 (f1057) |
|---|---|---|
| v700 | d1=27 / d2=3,194,990 → f1056 是 f1055 的复制 | d1=3,194,990 / d2=1,829,469 / d3=3,060,369 → **离群 0.391** |
| v702 | 同上（未修） | 同上（未修） |
| v703 | d1/d2 归零 | 离群 0.012 → **已清** |

板图 `FLASH-BOARD-44s-R2417.png`（f1055-f1059，上行 v700、下行 v703）：

- v700：特写 → 特写 → **男女玻璃倒影中景（仅 1 帧）** → 全景 → 全景。第 1057 帧是一整镜闪帧，1/24s 的完全换画，属肉眼可见瑕疵。
- v703：特写 → 特写 → 特写 → 全景 → 全景。闪帧被替换为前一帧，代价=该特写镜静止 3 帧（125ms）。静态特写上的 125ms 静止，观感代价远低于 1 帧整镜闪。

**结论：在已捕获的三版里，v703 是唯一「无可见弹出、无闪帧」版；v700/v702 带 44.042s 闪帧。**

## 四、诚实边界

1. 本轮与在执会话存在**版本竞态**：v704（00:22 出、550.2MB）在复核中被删除并由 v705（00:24 起写盘、捕获时 0B）替代。本件只对 **v700 / v702 / v703** 三版给出定档，v704 及以后未定档。
2. 只覆盖 pop/闪帧一项。R2416 §四 的三项缺项（C 项重复镜改构图 1.34x、两件音轨响度、全片解码扫描）本轮**仍未复核**，不继承任何结论。
3. 亮度/调色/构图质量不在本件射程（归导演席）。
4. 检测器为 240×136 代理指标：能抓整镜闪帧（百万量级差），抓不到细微局部形变。

## 五、给在执会话的结论

- 派生基版建议改为 **v703 或其后继**；若必须以 v700 为基，需补修第 1057 帧。
- 后续每出一版，可直接 `python src/mv_pop_probe.py --video <mp4> --repair-json <mp4>.repair.json` 自检，一次约数秒，不占 GPU。
