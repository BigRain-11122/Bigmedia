# em 预算梯档判例库（L-卡版式 · 1080×1080）

## 公式与常数

- em 预算 = (画布宽 − 左右边距和) / h2_size。现行卡：1080 − 160 = 920px 可用宽。
- 全角字 = 1.0em；ASCII/拉丁 ≈ 0.55em（R295 拉丁估宽法，QUANT/GAME/MEDIA/X026/C-000NN 等混排行先估后核）。
- 梯档（降序实战带）：50 → 46 → 44 → 40 → 36 → 32 → 28。**选最大可行档**，被排除才降档。

## 判例（选档驱动行型）

| h2_size | em 预算 | 判例 |
|---|---|---|
| 50 | 18.4em | 钩子 18.0em·城区职业行 16.10em（50 档带内） |
| 46 | 20.0em | 钩子 19.0em·城区职业行 19.10em 余量 0.90em；**19.0em==20.0 零余量=不入**（R293 像素级重叠教训） |
| 44 | 20.91em | 信条/钩子双 20.0em·物种行 20.15em（拉丁混排最长驱动） |
| 40 | 23.0em | 钩子 22.0em·信条 21.0em（信条行驱动首例） |
| 36 | 25.6em | 钩子 25 全角字（系列最长钩） |
| 32 | 28.75em | REACT 热点行 32.10em（ladder 参数化入 build 后首用） |
| 28 | 32.9em | REACT 长热点标题档 |

## 硬律

- **零余量排除律**：行宽 == 预算 = 像素级重叠风险，必须正余量（余量 ≥0.2em 入档口径）。
- **orphan-tail ≥2 glyphs**：折行后孤尾 <2 字 = FAIL（压底部来源行即像素级文字重叠）。
- **前置算行宽 → 选档 → 出图 → 复验**；禁出图后盲改参数（`cards_size` 对 H1/H2 分支无效参数面 = R293 实证）。
- 全分辨率复核惯例：tile 缩采样失读 = 读数手段问题非画面问题（R189 定谳）。
- 修参只动版式参数（h2_size 档位），文本 verbatim 零动；复验仍走验图五检全套。
